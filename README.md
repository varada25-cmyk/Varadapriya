## Tasks Performed

- Constructed the Karate Club social network using NetworkX.
- Created the adjacency matrix and calculated node degrees.
- Built the modularity matrix to measure community structure.
- Used eigenvalue and eigenvector analysis to identify community divisions.
- Implemented recursive spectral bisection to detect communities.
- Evaluated community divisions using modularity and compared results with NetworkX.
- Compared detected communities with the actual historical club division.
- Visualized community partitions at each iteration.
- Calculated and analysed degree, betweenness, and closeness centralities, along with clustering coefficients.
- Plotted the evolution of node-level metrics across iterations.
- Compared the standard modularity method with Newman's generalized method.
